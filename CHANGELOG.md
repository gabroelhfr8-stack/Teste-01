# Changelog

## 0.3.0 — Visual and structural overhaul

### Wards and structure
- `MvpWardEffects` (one class with two 32-way switches) is gone. Every ward has its own effect class, grouped by
  category (`source`, `detection`, `buff`, `utility`, `hostile`, `structure`, `event`) behind a `WardEffects` registry.
- New `WardArea`: every entity and block query now uses the same **sphere** the client draws. Wards that used to query
  a cube of half-side `range` cover about half the volume now (see `docs/KNOWN_ISSUES.md`).
- New `WardCategory`, `WardStyles` (colours and shell style per ward) and `EntityCooldowns`.
- Static active-ward indexes are cleared when the server stops.
- Cosmetic options moved out of `selarium-common.toml` into the new client-only `selarium-client.toml`
  (`vfxQuality`, `wardShells`, `shellOpacity`, sigil animations, mana HUD).

### Visuals
- Every texture and model regenerated by a deterministic Python pipeline (`tools/art`): 32x32 pixel art, faceted
  crystals in four growth stages, a gilded Arcane Grinder (with a lit state), Mana Tank with animated fluid,
  Inscription Bench, 3D books and scrolls, animated Citadel wall and Tangible barrier, 32 ward glyphs and rune rings.
- New sigil renderer: chalk circle, dust marks, tinted glyph, rotating light rings, orbiting runes, a floating focus
  crystal, a light column and a translucent field shell per ward (`SOFT`, `HEX` or `RUNES`).
- Custom glow particles (`wisp`, `spark`, `rune`, `ring`) sent by the server in each ward's colour: ward cycles pulse,
  affected creatures shimmer, events burst.
- Gauge-style mana HUD; scroll seals are tinted with the ward's colour.
- Ward activation, deactivation and scroll casting have sound cues; a successful attunement ritual plays a chime with a
  ring and rune burst.

### Progression and text
- 17 advancements (English and Portuguese) from the first crystal to discovering every ward.
- Scrolls remember the creator's name; tooltips show the ward (tinted), its category and the creator instead of a UUID.
- Portuguese translation restored with accents; dusts are named consistently ("Poeira de Foco Refinada") in items, GUI
  labels and the Codex.

### Tooling and CI
- GitHub Actions: asset validation, compile + Forge GameTests + server-log check, and a client smoke test that boots
  the real game under Xvfb with software OpenGL and takes screenshots.
- `tools/validate_assets.py`, `tools/art/build_all.py`, `tools/gen_docs.py`, `tools/preview/` (see `docs/BUILD_NOTES.md`).
- New docs: `README.md`, `docs/ARCHITECTURE.md`, generated `docs/WARDS.md`.

### Removed
- Old PowerShell tools, the committed `dist/` build output and about 70 replaced or unused textures.

### Fixed
- Latent bug: the Fertility ward could use the same animal twice in one cycle.
